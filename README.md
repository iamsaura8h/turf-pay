# Turf Pay Tracker

i want a create a minimalist website with good ui compatible with  mobile responsive, tailwind css and that supabase db. can use lovebale's website for inspiration for minimalism.

the app what it does is it solves a problem with this: i go to a turf football, there i am quite a elder so i need to pay the turn owner the turf price played for , for an hour it is say 1000rs, and there are 14 ppl  (kids + adults) so some kids pay 100rs cash , some pay 86rs upi, some say they will pay later this and that. even though 86 is per head, some pay more, so i need to track how much more i got + who didnt pay and how much he has to pay + who paid online how much. did i get the total amount of 1200 if less or more then how much. so a proper tracking app.
